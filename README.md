# Lovecoin

A minimal static landing page for "$LOVE," a Solana token concept, displaying the token's
contract address.

## Purpose

A placeholder page pointing to a deployed Solana token contract — not an application, and not
associated with any exchange, wallet, or trading functionality.

## Features

- Displays the token's on-chain contract address

## Tech Stack

- Plain HTML, no framework, no build step

## Running Locally

Open `Index.html` directly in a browser.

## Status

**Experimental concept.** A single static page with no application logic, styling, or backend.
